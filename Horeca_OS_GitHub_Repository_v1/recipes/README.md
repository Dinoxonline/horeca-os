# Recepturen

Er zijn 15 receptuurkaarten voorbereid:

1. BBQ Chicken
2. Varkensribs
3. Halal Kalfsribs
4. Jerk Chicken
5. Chicken Saté
6. Beefsteak
7. White Tiger Garnalen
8. Caribbean Chicken Wings
9. Surinaamse kipworst
10. Coleslaw Caribbean Style
11. Caribische rijst
12. Funchi Fries
13. Pika Balletjes
14. Caribbean Cheese Balls
15. Huisgemaakte sauzen en marinades

Per recept moeten exact worden vastgelegd:

- ingrediënten
- hoeveelheden
- batchgrootte
- opbrengst
- standaardportie
- bereidingswijze
- tijden
- temperaturen
- bewaartermijn
- allergenen
- verkoopprijs
