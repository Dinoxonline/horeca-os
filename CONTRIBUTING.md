# Bijdragen

## Branches

- `main`: productie
- `develop`: integratie
- `feature/...`: nieuwe functionaliteit
- `fix/...`: bugfix

## Werkwijze

1. maak een featurebranch
2. voer wijzigingen door
3. controleer dat geen secrets zijn toegevoegd
4. open een pull request
5. laat build en controles uitvoeren
6. merge pas na controle

## Commitberichten

Voorbeelden:

- `feat: add products dashboard`
- `fix: prevent duplicate calendar events`
- `security: restrict anonymous database grants`
- `docs: update backup procedure`
